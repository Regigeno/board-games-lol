# Parlor

Fifteen board games on one screen. Sit down, pass the device, and play.

Secret hands stay covered. When the turn changes in UNO, Clue, Shithead, Catan, Plague Inc: The Board Game, or Diplomacy, the table shows **It is now Player’s turn** and waits for that player to continue.

## Play

```bash
npm install
npm run dev
```

Open the printed local URL. Pick a game, name the seats, and start.

```bash
npm test
npm run build
```

## Games

Chess, Checkers, Backgammon, Monopoly, Blackjack, UNO, Plague Inc: The Board Game, Clue, Shithead, Solitaire, Catan, Sorry, Chutes & Ladders, The Game of Life, and Diplomacy.

How to play is on each table. A few shortcuts are called out there: Diplomacy cuts support on any attack from outside the province being supported into, and The Game of Life uses a shortened track.
